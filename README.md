# Implementasi Struktur Data Menggunakan PHP

## Deskripsi

Project ini merupakan implementasi sederhana dari beberapa konsep dasar struktur data menggunakan bahasa pemrograman PHP. Project ini dibuat sebagai bagian dari proses pembelajaran untuk memahami cara kerja dan penerapan struktur data dalam pemrograman.

Struktur data yang digunakan dalam project ini meliputi **Array, Linked List, dan Stack**. Setiap struktur data dibuat dalam halaman yang terpisah dan dilengkapi dengan tampilan antarmuka berbasis web agar proses penggunaan dan pengamatannya lebih mudah dipahami.

Selain PHP, project ini juga menggunakan HTML, CSS, dan JavaScript untuk membuat tampilan halaman menjadi lebih interaktif.

---

## Tujuan

Adapun tujuan dari pembuatan project ini adalah:

1. Memahami konsep dasar struktur data Array, Linked List, dan Stack.
2. Mengetahui cara mengimplementasikan struktur data menggunakan PHP.
3. Memahami operasi dasar yang terdapat pada masing-masing struktur data.
4. Menerapkan HTML dan CSS dalam pembuatan antarmuka sederhana.
5. Menggunakan JavaScript untuk memberikan interaksi pada halaman web.
6. Meningkatkan pemahaman mengenai hubungan antara struktur data dan implementasinya dalam program.

---
